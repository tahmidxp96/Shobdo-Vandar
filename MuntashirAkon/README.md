# MuntashirAkon Bangla-to-Bangla Dictionary Dataset

This directory contains the large-scale monolingual Bangla-to-Bangla dictionary database acquired from the open-source **[MuntashirAkon/BanglaDictionary](https://github.com/MuntashirAkon/BanglaDictionary)** project.

## Credits & Attributions
* **Author/Developer**: Muntashir Al-Islam ([MuntashirAkon](https://github.com/MuntashirAkon))
* **Repository**: [https://github.com/MuntashirAkon/BanglaDictionary](https://github.com/MuntashirAkon/BanglaDictionary)
* **Dataset Size**: 46,558 entries of rich monolingual definitions.
